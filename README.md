# atolye-paket

Belgesel hattının (kod + ortak beyin + kurallar + Claude hook'ları) taşınabilir kopyası. Özel repo; hesap, çerez, anahtar içermez.

**Başlangıç:** Claude Code'u bu klasörde aç ve şunu yaz: *"KURULUM_REHBERI.md'yi baştan sona uygula."*

- `kur.py`: paketi kullanıcı klasörüne kurar ya da günceller (yolları çevirir, değiştirilmiş dosyaları ezmez)
- `requirements.txt`: ana Python paketleri
- `ev/`: kullanıcı klasörünün aynası (kur.py buradan kopyalar)
